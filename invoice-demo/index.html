What to look for

    
    
      
  • Clean invoice: every line closes (quantity × unit cost = value) and the lines add up to the QR code for each VAT rate, so the invoice is PROVEN and price changes are pre-approved.
    • 
      
  • Invoice with traps: two lines for one product, a discount and a generic product. These cases go to a person instead of being guessed. They come from real findings of two independent code audits.
    • 
      
  • Missing page: the lines no longer add up to the QR code, so the gap shows up and nothing is pre-approved.
    • 
      
  • Write and undo: the writer only applies the exact plan that was simulated (fingerprint), makes a verified backup first and writes the undo log before the commit.
